# Framework for mathematics education topic reports

Use as a flexible scaffold, not a mandatory template. Adjust to the institution's required format and the actual research design.

## Front matter

Title; author/organization; abstract or executive summary if required; keywords; table of contents; list of figures/tables; abbreviations.

## Introduction / problem statement

Context and curricular relevance; specific instructional problem; evidence establishing the problem; purpose; research/design questions; participants and content scope; methods and data sources; contribution; report map. Separate broad motivation from the precise problem. Avoid claiming a gap without a literature search.

## Chapter 1. Theoretical and curricular foundations

Define the mathematical content and grade-appropriate learning outcomes. Select only the theoretical constructs needed to interpret the learning difficulty and guide design (for example, mathematical modelling, problem solving, mathematical communication, formative assessment, or Socratic questioning). State each construct's source, operational meaning, and consequence for the intervention. A brief literature synthesis should compare relevant findings and identify the unresolved design need; it should not become a glossary.

## Chapter 2. Practical context and needs analysis

Analyze the current curriculum and learning outcomes; compare selected approved textbooks and teacher materials using explicit criteria; describe the local setting and learners; present baseline evidence (student work, diagnostic tasks, observations, interviews, or teacher records) with dates, sample, collection procedure, coding criteria, and limitations. Report frequencies only when calculated from data. Distinguish observed errors from hypotheses about their causes. End with a traceable list of design requirements.

## Chapter 3. Design of the pedagogical resource/intervention

State design principles and objective-to-evidence alignment. Describe the resource architecture, sequence, classroom use, teacher facilitation, anticipated responses, scaffolds, differentiation, and assessment. For question systems, show prompt → intended reasoning → diagnostic interpretation → contingent follow-up → evidence of progress. Include full sample materials and answer/rationale notes. Explain revisions using feedback or pilot evidence where available.

## Chapter 4. Implementation and evaluation (if actually conducted)

Give setting, participants, duration, procedure, instruments, ethics/privacy, analysis method, results, examples of student work, and limitations. Match claims to evidence; distinguish implementation feasibility from learning outcomes. If no implementation occurred, do not fabricate this chapter: present an evaluation plan, or adapt the structure to the required assignment.

## Conclusion and recommendations

Answer the study questions, summarize the contribution and limits, and propose specific next steps. Do not introduce new results.

## Appendices and references

Attach instruments, task sheets, scoring rubrics, anonymized work samples, permissions where relevant, and coding schemes. Cite sources consistently and include only sources actually consulted.

## Common terminology distinctions

- **Yêu cầu cần đạt**: curriculum outcomes, quoted or paraphrased precisely.
- **Năng lực mô hình hoá toán học**: formulate a real situation mathematically, work with the model, interpret and evaluate results in context.
- **Sai lầm**: a documented incorrect response or recurring pattern; **khó khăn** is broader and needs evidence; **ngộ nhận** implies a stable misconception and needs stronger evidence.
- **Câu hỏi gợi mở kiểu Socratic**: a planned, contingent sequence that elicits and examines learner reasoning; it is not synonymous with any open question.
- **Đánh giá thường xuyên/đánh giá vì sự tiến bộ**: evidence used to inform learning and teaching during instruction; name the instrument and how its evidence is used.
- **Hệ bất phương trình bậc nhất hai ẩn**: constraints define a feasible region; a linear objective may be optimized on that region when the task asks for it. Keep linear programming formalism proportionate to the curriculum and label extension material.
